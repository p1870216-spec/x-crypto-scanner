# X Crypto Following Scanner

Локальная программа для Windows. Берёт аккаунт X (по умолчанию **@Rus_Khairullin**),
собирает всех, на кого он подписан, и определяет, кто из них относится
к Crypto Twitter: **Crypto Score 0–100**, категория, специализации и объяснение
каждой оценки. Результат — Excel, CSV и текстовый отчёт.

## Как это работает

Данные берутся из сервиса **twitterapi.io** (режим `api`, основной).

Почему не напрямую из браузера: X отдаёт из чужого списка подписок только
около 50 аккаунтов и закрывает подгрузку. Проверено на живом X — у аккаунта
с 1487 подписками приходит ровно 50, и это не зависит от того, под каким
аккаунтом смотреть. Через сервис тот же список собирается целиком за 21 секунду.

Браузерный режим (`DATA_SOURCE = "browser"` в config.py) оставлен запасным.

## Что программа НЕ делает

- не использует официальный X API, не просит его ключи и токены;
- не спрашивает ваш логин, пароль и код 2FA;
- не подписывается, не отписывается, не лайкает, не постит, не пишет сообщения;
- никуда не отправляет ваши данные: на сервис уходят только имена публичных
  аккаунтов, которые нужно проверить;
- ключ от сервиса не попадает ни в журналы, ни в кеш, ни в выгрузки.

В запасном браузерном режиме дополнительно: не кликает по страницам X
(кнопка «Following» при клике отписывает от аккаунта), не нажимает клавиши
(у X есть горячие клавиши, например `l` — лайк) и не трогает ваши вкладки.

## Установка (один раз)

Нужен Python 3.10 или новее.

```bat
cd C:\Users\Legion\Desktop\x_scanner
python -m venv venv
venv\Scripts\pip install -r requirements.txt
```

Затем заведите аккаунт на twitterapi.io, пополните баланс на пару долларов
и создайте рядом с `main.py` файл **`.env`**:

```
TWITTERAPI_KEY=ваш_ключ
```

Файл `.env` в репозиторий не попадает. Образец — в `.env.example`.

Проверка, что всё на месте:

```bat
run.bat --probe-api
```

## Запуск

```bat
run.bat --trial 20
```

Пробный прогон: соберёт весь список подписок, оценит все профили и разберёт
посты у 20 лучших кандидатов. Стоит около 12 центов.

Когда результат устроит — полный прогон:

```bat
run.bat --trial 0 --yes
```

Прервать можно `Ctrl+C` — собранное сохраняется, следующий запуск продолжит
с того же места и не станет платить за уже полученные данные повторно.

### Сколько это стоит

| Что | Цена |
|---|---|
| список подписок (1487 аккаунтов) | $0.015 |
| обогащение профилей | $0.15 |
| посты одного кандидата (40 штук) | $0.006 |
| пробный прогон на 20 кандидатах | ~$0.12 |
| полный прогон с 724 кандидатами | ~$4.5 |

Перед тратой дороже $1 программа спрашивает подтверждение (порог —
`CONFIRM_COST_ABOVE` в config.py). В конце печатает фактический расход.

## Команды

| Команда | Что делает |
|---|---|
| `run.bat` | цели из `targets.txt`, иначе `TARGET_USERNAME` из `config.py` |
| `run.bat --target NAME` | одна конкретная цель (без `@`) |
| `run.bat --trial 20` | разобрать посты только у 20 кандидатов (пробный прогон) |
| `run.bat --trial 0` | снять ограничение, разобрать всех кандидатов |
| `run.bat --max-following 50` | собрать не более 50 подписок (для проверки) |
| `run.bat --no-tweets` | не анализировать посты, оценка только по профилю |
| `run.bat --force-refresh` | игнорировать кеш и собрать всё заново |
| `run.bat --rescore` | пересчитать оценки **из кеша: 0 запросов, $0.00** |
| `run.bat --probe-api` | проверить ключ и показать, что отдаёт сервис |
| `run.bat --yes` | не спрашивать подтверждение расходов |
| `run.bat --source browser` | запасной режим через Chrome (даст только ~50 подписок) |
| `run.bat --check-connection` | проверка Chrome (для запасного режима) |

Прервать работу можно `Ctrl+C` — прогресс сохраняется, следующий запуск
продолжит с места остановки.

## Настройка

**`config.py`** — все параметры с комментариями: цель, лимиты, скорость,
пороги, кеш.

Полезное для первых запусков:

```python
DATA_SOURCE = "api"     # "api" (полный список) | "browser" (запасной, ~50)
MAX_FOLLOWING = None    # None = собрать всех
TRIAL_CANDIDATES = 20   # сколько кандидатов разбирать по постам
TWEETS_PER_USER = 30    # сервис отдаёт страницами по 20, берётся 40
ANALYZE_TWEETS = True   # анализ постов кандидатов
```

**`keywords.yaml`** — словари и веса: крипто-термины (английские и русские),
контекстные слова, тикеры, домены, пороги компонентов оценки и правила
специализаций. После правки файла пересчитайте результаты из кеша — это
**бесплатно и без единого запроса**, сырые тексты постов уже сохранены:

```bat
run.bat --rescore
```

Команда покажет, у кого и как изменилась оценка.

**`targets.txt`** — если файл существует и не пуст, обрабатываются все аккаунты
из него по очереди, у каждого свой кеш и свои выгрузки.

## Результаты

```
output\<target>\
  <target>_analysis.xlsx    листы ALL FOLLOWING, CRYPTO, STRONG_CRYPTO,
                            TRADERS, ANALYSTS, STATISTICS
  <target>_all.csv
  <target>_crypto.csv
  <target>_strong_crypto.csv
  <target>_report.txt       краткий отчёт и TOP 20
  errors.log                ошибки отдельных аккаунтов
  run.log                   подробный ход работы
```

Промежуточные данные — в `cache\<target>\`. Их можно не трогать: они нужны
для продолжения после сбоя и для `--rescore`.

### Как читается Crypto Score

`crypto_score = P + T + S + F` (0–100)

| | Компонент | Максимум |
|---|---|---|
| **P** | профиль: bio, имя, username, сайт и ссылки | 40 |
| **T** | доля крипто-постов среди последних постов | 40 |
| **S** | особые сигналы: торговля, on-chain, аирдропы | 10 |
| **F** | подписчики (только при наличии крипто-признаков) | 10 |

| Балл | Категория |
|---|---|
| 0–19 | NOT CRYPTO |
| 20–39 | POSSIBLE CRYPTO |
| 40–59 | CRYPTO RELATED |
| 60–79 | CRYPTO INFLUENCER |
| 80–100 | STRONG CRYPTO CT |

В колонке `reason` записано, из чего сложился балл, например:
`Bio: "crypto trader" (+30); 21/30 recent posts are crypto-related (+40); 184K followers (+6)`.

## Если что-то пошло не так

| Сообщение | Что делать |
|---|---|
| Не найден ключ twitterapi.io | создайте файл `.env` со строкой `TWITTERAPI_KEY=...` |
| Ключ не принят (HTTP 401/403) | проверьте ключ в `.env` |
| Кончились кредиты (HTTP 402) | пополните баланс на twitterapi.io |
| Лимит запросов сервиса (HTTP 429) | программа сама подождёт и повторит |
| Собрано меньше 95% подписок | предупреждение попадёт в отчёт и в STATISTICS |
| Не удалось подключиться к Chrome | только для запасного режима: запустите `start_chrome.bat` |
| X требует входа | запасной режим: войдите в x.com в окне `start_chrome.bat` |

Ошибка на отдельном аккаунте не останавливает работу — запись попадает
в `errors.log`, сканер идёт дальше.
